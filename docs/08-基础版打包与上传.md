## 重新打包

在项目根目录运行：

```powershell
python team-tools/package-baseline.py
```

脚本仅选取已受 Git 管理的编译运行文件，拒绝环境文件，并核对基础编译器未偏离上游。输出 ZIP 和同名 JSON（文件大小、SHA256、源提交）。后续实现优化时应使用新的版本与打包规则。

## 用户上传步骤

1. 进入 ARC-Bench: Web Application 竞赛页的 New submission。
2. runtime 选择 Python，上传上述 ZIP；提交名建议 `webapp-builder-B0-20261104`。
3. 填写自己 API 服务的 Base URL 和 API Key，确认该服务支持代码中的模型名。
4. Save submission；保存 Agent 快照后打开 BookStack 任务，选择该快照开始运行。
5. 保存 submission/run ID、官方测试通过数、token、成本、耗时和报告链接，填写 experiments/runs.csv。

平台文档入口：https://arc-bench.com/docs/agent 。本次检查发现其输入调用方式与参考实现兼容，生成模板已有 deploy.sh 供 Runner 安装依赖、构建并启动。没有登录或代为提交。
