# 根据用户需求生成网站的通用 Agent 课程项目

建立日期：2026-11-03（Asia/Shanghai）。本目录是最终课程项目的独立工作区。

## 目标与交付

构建一个能够根据用户需求生成网站的通用 Agent：接收自然语言、结构化需求和可选参考图，完成需求理解、规划、前后端与数据库生成、运行验证和自动修复，交付网站源码、启动说明和验证报告。

BookStack 只是首个评测任务，用来复现基线、诊断问题。项目的通用能力还需通过其他网站任务和自定义用户需求验证。同一个 Agent 版本应能在不同输入上运行；具体业务、初始数据和时钟规则属于任务输入，不写死在编译核心。初期固定 React + Express + SQLite，不把“通用”解释成已支持所有技术栈或任意复杂网站。

1. 接受用户需求并生成可运行网站的统一入口，以及可复现的基线版本、合法提交包和平台运行记录。
2. 将任务适配与编译核心分离，具有需求追踪、受限修复和可观测指标的优化版本。
3. BookStack 对照实验、至少一个其他网站任务的泛化验证、自定义需求演示、失败分析与消融结果。
4. 小组协作仓库、操作文档、期中展示及最终报告材料。
