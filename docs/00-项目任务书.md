# ARC-Bench BookStack 课程项目

建立日期：2026-11-03（Asia/Shanghai）。本目录是最终课程项目的独立工作区。

## 目标与交付

基于需求编译智能体，在 ARC-Bench 的 BookStack 任务上，先复现参考实现，再验证准确率、稳定性、token 或时间成本的改进。优化对象是“生成 Web 应用的编译系统”，生成的 BookStack 应用是评测产物。

1. 可复现的基线版本、合法提交包及平台运行记录。
2. 有需求追踪、受限修复和可观测指标的优化版本。
3. 公平对比实验、失败案例分析和消融结果。
4. 小组协作仓库、操作文档、期中展示及最终报告材料。

## 汇报约束

以用户给出的最新补充为准：每组 **10 分钟，包含问答**。建议展示 7 分钟，问答 3 分钟。原通知中的 13 分钟与 8–10 分钟展示不再作为排练标准。本周随机选 11 组，具体汇报日期须以教师后续通知为准。地点：下院 211；公告课程时段 18:00–20:40。

模板六页依次为封面、Current Progress、Motivation、Proposed Performance Changes、Current/Potential Challenges、Next Step。具体讲稿见 `04-汇报提纲.md`。此次初步展示不计分，但用于期中演练。
