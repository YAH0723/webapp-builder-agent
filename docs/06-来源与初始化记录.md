## 后续同步上游

先在单独分支 fetch/diff，再决定合并；更新后重新跑基线，避免把上游变化与本组优化混为一谈。

```powershell
git fetch upstream
git log --oneline main..upstream/main
git diff main...upstream/main
```

本地初始标签 `baseline/upstream-2026-11-03` 标记上述上游 SHA；正式 B0 还需包含固定的平台适配，并另打标签。
